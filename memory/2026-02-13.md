# 2026-02-13 - Polymarket Paper Trading System

## New Project: Polymarket Paper Trading Bot

Penn requested a complete automated paper trading system for Polymarket prediction markets. Built from scratch.

### What Was Built

1. **API Client** (`api_client.py`)
   - Polymarket API wrapper
   - Market discovery and filtering
   - Real-time price fetching
   - Order book access

2. **Trading Bot** (`trading_bot.py`)
   - Mean-reversion strategy
   - Trade journaling (JSON)
   - Circuit breaker (3 consecutive losses)
   - Signal generation
   - Position sizing ($10 max per trade)

3. **Dashboard** (`dashboard_server.py`)
   - Flask web server on port 5001
   - Real-time stats display
   - Trade history table
   - P&L and Win/Loss charts
   - 30-second auto-refresh

4. **Configuration** (`config.yaml`)
   - Strategy parameters
   - Market selection
   - Risk limits
   - Logging settings

5. **Testing & Demo** (`bot_demo.py`, `test_api.py`)
   - Single-cycle execution
   - Market discovery
   - API testing

### Key Features

- ✅ Paper trading only (no real money)
- ✅ Configurable mean-reversion thresholds (oversold: 0.40, overbought: 0.60)
- ✅ Trade journal in JSON format
- ✅ Circuit breaker protection
- ✅ Position size limits
- ✅ Liquidity/volume filters
- ✅ Web dashboard with charts
- ✅ Real-time monitoring

**Note:** Polymarket doesn't have traditional "Up/Down" directional markets like Deribit. The system uses probability extremes to signal reversions.

### How It Works

1. Bot fetches market prices every 15 minutes (configurable)
2. Checks for oversold (YES < 40%) or overbought (YES > 60%) signals
3. If signal triggers, creates paper trade in `trades.json`
4. Tracks P&L, win rate, consecutive losses
5. Dashboard visualizes all stats in real-time

**Conservative strategy (fewer, bigger wins):**
