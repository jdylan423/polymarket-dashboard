QUICK START
═══════════════════════════════════════════════════════════════════════════════

Step 1: Configure
  $ cp .env.example .env
  $ nano .env
  (Fill in API keys and secrets)

Step 2: Install & Test
  $ npm install
  $ npm start
  (Verify: "✅ Bot daemon started successfully!")
  (Ctrl+C to stop)

Step 3: Deploy (Choose One)
  
  PM2 (Recommended):
    $ npm run pm2:start
    $ npm run pm2:logs
  
  Systemd:
    $ sudo cp solana-bot.service /etc/systemd/system/
    $ sudo systemctl enable solana-bot
    $ sudo systemctl start solana-bot
  
  Docker:
    $ npm run docker:build
    $ npm run docker:up

Step 4: Monitor (In Another Terminal)
  $ npm run dashboard
  
  Commands:
    r - Refresh
    p - Positions
    s - Sentiment
    q - Quit
